## Description

Main page seems to be a table of lesson combinations, giving us the lesson id combination (8 * 8 * 8 for 512 combinations) and the sample size of that lesson output. Each sub-page gives "Merged Drops" aka School Idol Badge, Money, and item drops for that lesson type.

Item drops seem to be lesson-combination agnostic, in that drops are calculated in a weighted manner per-lesson that is consistent with all possible lesson combinations. I.e. Performing 3 swim lessons at once gives the same result as running three separate swim lessons.

## Item Drops by Lesson

For each present that is given during a lesson, the result of that present is generated by a weight draw across the items that can drop in that lesson. The total weight of all items will ALWAYS equal 10k.

In code that would look like
```python
present_count = randint(0, 20) # Actual algorithm differs, see below for details.
for _ in range(present_count):
    item = choice([1700, 1200, 1200, 1200, 1200], [1000, 2000, 2500, 25000, 1000, 1000])
```
where the Id of the item is chosen according to the provided weight. Item drops are independent of each other.
